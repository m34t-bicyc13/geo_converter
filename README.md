# Geo Converter

Локальное веб-приложение для просмотра `geosite.dat` (формат xray/v2ray) и конвертации
категорий в upstream-правила AdGuard Home:

```
[/youtube.com/googlevideo.com/ytimg.com/]tls://1.1.1.1
```

## Возможности

- Источники: пресеты (Loyalsoldier, v2fly, runetfreedom, Iran), любой URL, файл с диска.
  Можно загрузить несколько источников одновременно.
- Список категорий с фильтром и сортировкой, просмотр правил с типами и атрибутами.
- Поиск домена: в каких категориях есть правила, которые на него сработают
  (семантика xray: `domain`, `full`, `keyword`, `regexp`), или поиск подстроки.
- Объединение нескольких категорий (в том числе из разных источников) в один список
  с дедупликацией и удалением поддоменов, уже покрытых родителем.
- Копирование результата или скачивание `.txt`.

## Запуск

Нужен Node.js 22.18+ (TypeScript-сервер запускается без сборки).

```bash
npm install
```

```bash
npm start
```

Команда соберёт фронтенд и запустит сервер на http://127.0.0.1:5180 (порт меняется переменной `PORT`).

Для разработки — `npm run dev` (vite с горячей перезагрузкой, http://127.0.0.1:5173),
тесты — `npm test`.

## Как типы geosite переносятся в AdGuard Home

| geosite    | upstream AGH       | Примечание |
|------------|--------------------|------------|
| `domain:`  | `[/example.com/]`  | Без потерь: домен и все поддомены |
| `full:`    | `[/example.com/]`  | Точного аналога нет — захватит и поддомены. Можно пропускать настройкой |
| `keyword:` | —                  | Не поддерживается, попадает в отчёт о пропущенных |
| `regexp:`  | —                  | Не поддерживается, попадает в отчёт о пропущенных |

## Подключение в AdGuard Home

**Небольшие списки** — вставить в *Настройки → Настройки DNS → Upstream DNS-серверы*
рядом с основными серверами.

**Большие списки** (десятки тысяч доменов) лучше подключать файлом — в `AdGuardHome.yaml`:

```yaml
dns:
  upstream_dns_file: /opt/AdGuardHome/upstream.txt
```

Файл **заменяет** весь список upstream, поэтому основные серверы (без доменов) должны быть
в нём же. Для этого в приложении есть поле «Основные upstream» — эти строки встанут в начало
файла. После замены файла AdGuard Home нужно перезапустить.

## Устройство

- `src/lib/geosite.ts` — свой декодер protobuf: сначала индексирует категории
  (имена, границы, число правил), домены декодирует лениво при открытии категории.
  Файл runetfreedom на 75 МБ / 3 млн правил индексируется за ~60 мс.
- `src/lib/convert.ts` — конвертация в upstream-синтаксис.
- `src/lib/match.ts` — проверка срабатывания правил на хост.
- `server/proxy.ts` — прокси `/api/fetch?url=…`: GitHub Releases не отдаёт CORS-заголовки,
  поэтому браузер не может скачать файл сам. Сервер слушает только `127.0.0.1`.
